# Pratik Sawant — Personal Portfolio

A personal portfolio focused on AI and full stack development, built with Next.js, React and TypeScript.

## Tech stack

- Next.js 15 and React 19
- TypeScript
- Tailwind CSS and PostCSS
- Framer Motion for animation
- Lucide React for icons

## Run locally

```bash
git clone https://github.com/Pratiksawan/Pratik-portfolio.git
cd Pratik-portfolio
npm install
npm run dev
```

Use the local address printed by the development server.

## Production build

```bash
npm run build
npm start
```

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start development through the project's development script |
| `npm run dev:bare` | Start the Next.js development server directly |
| `npm run build` | Build the application for production |
| `npm start` | Serve the production build |
